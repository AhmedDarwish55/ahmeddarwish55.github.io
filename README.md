# Ahmed Darwish Portfolio Website

This is a static portfolio website (`index.html`). It is ready to publish, but it is **not live yet**.

## Publish free with GitHub Pages
1. Sign in to GitHub.
2. Create a **public** repository named `ahmeddarwish55.github.io`.
3. Upload `index.html` from this folder to the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. After GitHub finishes publishing, the website should be available at `https://ahmeddarwish55.github.io/`.

Review contact details and all claims before publishing. Drone/UAV experience is described at a professional level; confidential operational details are intentionally generalized.
